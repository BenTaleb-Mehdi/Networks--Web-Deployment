Step-by-Step Installation & Configuration Guide

Nginx + PHP-FPM

What Are We Installing?

🗄️
Nginx
The Web Server. It receives HTTP requests and manages static files and security.
⚙️
PHP-FPM
The Engine. It processes the Laravel PHP code in the background for Nginx.
🔑
Permissions
The Security. Ensuring Nginx has the right to write logs and cache files.
Step 01

System Prep

Update & Install Core
Before installing anything, we must update the package list and install the main servers.
sudo apt update sudo apt install nginx php-fpm -y
🔄 Refresh the repository list.
⬇️ Install the Nginx binary.
🔧 Install the FastCGI Process Manager.
Step 02

Laravel Requirements

Laravel requires specific PHP extensions to handle database, text, and security operations.

sudo apt install php-mysql php-mbstring php-xml php-bcmath php-curl php-zip -y
PDO: Database connection.
Mbstring: Text processing.
XML/JSON: Data format support.
Step 03

App Deployment

Move Your Files
Place your Laravel project in the standard web directory /var/www/.
sudo mv ~/my-project /var/www/laravel-app
📁 Create a clean project folder.
📋 Move files from home to /var/www.
💻 Use composer if installing fresh.
Step 04

The Server Block

Create a configuration file in /etc/nginx/sites-available/laravel. Point the root to the public folder.

server { listen 80; server_name monprojet.local; root /var/www/laravel-app/public; index index.php; location / { try_files $uri $uri/ /index.php?$query_string; } }
Step 05

Enabling the Site

Symbolic Link & Reload
Tell Nginx that this site is now "enabled" and restart the service.
sudo ln -s /etc/nginx/sites-available/laravel \ /etc/nginx/sites-enabled/ sudo nginx -t sudo systemctl reload nginx
🔗 Link available sites to enabled sites.
🔍 nginx -t checks for syntax errors.
▶️ Reload applies changes without downtime.
Step 06

Folder Permissions

Give the web server user (www-data) ownership and write access to specific folders.

sudo chown -R www-data:www-data /var/www/laravel-app sudo chmod -R 775 /var/www/laravel-app/storage sudo chmod -R 775 /var/www/laravel-app/bootstrap/cache
⚠️ Without this, you will get a "Permission Denied" error.
Step 07

Final Test

🌐
Access Your Project
Open your browser and type your VM's IP address or your local URL:
http://monprojet.local
If you see the Laravel logo, your manual deployment is successful!
